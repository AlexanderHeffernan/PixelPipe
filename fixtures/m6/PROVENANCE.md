# M6 fixture provenance

The palette and conversion recipe in this directory were authored from scratch for PixelPipe's M6 tests and documentation. They describe a synthetic four-color signal-flare fixture and are dedicated to the public domain under CC0-1.0.

No Last Light, Painter, PoC, third-party, or user-provided image is included. M6's integration test renders the existing synthetic CC0 M1 indexed raster in memory when it needs reference PNG bytes.
